# 💰 Smart Expense Categorization & Analytics

A Machine Learning powered expense tracker that automatically
categorizes transaction descriptions and provides spending analytics.

## 🚀 Features

- Automatic expense category prediction
- TF-IDF text feature extraction
- Logistic Regression classification
- Expense amount and date tracking
- Category-wise spending analytics
- Monthly spending trends
- Budget alerts
- CSV export
- Streamlit web interface

## 🧠 Machine Learning Workflow

Dataset
   ↓
Data Cleaning
   ↓
TF-IDF Vectorization
   ↓
Train-Test Split
   ↓
Logistic Regression
   ↓
Model Evaluation
   ↓
Expense Category Prediction
